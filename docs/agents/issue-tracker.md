# Issue tracker

GitHub Issuesを仕様と実装ticketの正本として使用する。

- Repository: `nomadoor/ComfyUI-Workflow-Image-Export`
- Default branch: `main`
- Issue、仕様、ticketの本文はproject prose languageで記述する。
- Template headings、labels、identifiers、GitHub keywords、canonical termsは英語を維持する。
- 仕様とticketは、作成前に内容と公開について明示的な承認を得る。
- ticketは親仕様へリンクし、可能ならGitHubのnative dependencyでblocking関係を表す。
- 実装可能になったticketだけに`ready-for-agent`を付与する。
- 完了PRは`Closes #N`で実装ticketを閉じる。親仕様は全範囲が完了するまで閉じない。

Issueやコメントを勝手に投稿してはならない。投稿にはユーザーの明示的な承認が必要である。
